ℹ️ About Filecoin

Filecoin is a decentralized storage network designed to store humanity's most important information. This demo showcases integration with Filecoin using the iso-filecoin library and Wallet Standard.

Supported Features:

  • 🔗 Wallet connection and account management
  • 💸 FIL token transfers
  • ✍️ Message signing
  • 🎯 Address validation
  • 📡 Real-time event listening
