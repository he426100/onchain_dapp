ℹ️ Technical Features

  • 🔄 Unified Interface: Same API for all wallet types
  • 🌐 Network Switching: Mainnet ↔ Testnet support
  • 🔐 Multiple Signature Types: SECP256K1 and BLS support
  • 📱 Event-Driven: Real-time connection status updates
  • 🛡️ Type Safety: Full TypeScript definitions
  • 🎯 Account Management: HD derivation path support

📚 Supported Adapters

  • WalletAdapterFilsnap: MetaMask Snap integration
  • WalletAdapterHd: BIP-39 mnemonic-based wallets
  • WalletAdapterLedger: Ledger hardware wallets
  • WalletAdapterRaw: Private key-based wallets
